Редактор квитанцій

Завантажте оригінальну квитанцію як файл 'receipt.png' у ту ж папку.

Натисніть кнопку нижче, щоб додати поле.

Двічі клацніть на доданому полі, щоб змінити текст.

Перетягніть поле, щоб перекрити старий текст.

Використовуйте 'Arial' для більшості тексту. 'Courier New' підходить для деяких номерів рахунків.
